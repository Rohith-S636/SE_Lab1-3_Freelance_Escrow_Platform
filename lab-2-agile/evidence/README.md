# Jira Evidence — Capture Notes

This folder is reserved for **genuine screenshots captured from the FEP Jira project UI**. No synthetic or recreated screenshots are included.

Add these files after capturing them from Jira:

| Filename | What the screenshot should show |
|---|---|
| jira-epic.png | FEP-1 Epic title, description, and project context |
| jira-backlog.png | FEP backlog with the nine stories, priorities, story points, and sprint allocation |
| sprint-1-report.png | Sprint 1 report showing FEP-2–FEP-4 (3 stories, 18 points) |
| sprint-2-report.png | Sprint 2 report, including the “Issues completed outside this sprint” classification |
| sprint-3-report.png | Sprint 3 report, including the “Issues completed outside this sprint” classification |

## Capture guidance

1. Open the linked Jira project using your own signed-in account.
2. Capture the actual Jira page using the operating system screenshot tool.
3. Keep the sprint name, issue keys, report section headings, and point totals visible.
4. Do not crop away the “completed outside this sprint” classification; it is part of the recorded history and must be disclosed.
5. Do not edit screenshots to make the sprint reports appear different from Jira.
